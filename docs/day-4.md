# Day 4 — WebSockets and Frontend Integration

**Outcome:** Show live device telemetry in the React dashboard.

| Block | Topics — one-line guide |
|---|---|
| Hour 1 | WebSocket handshake, persistent connections, messages, lifecycle and reconnect strategy. |
| Hour 2 | Implement a WebSocket endpoint and publish telemetry updates from the backend. |
| Hour 3 | Connect React/TypeScript, model typed messages and update application state. |
| Hour 4 | Build device status cards, telemetry charts and recent-reading views. |
| Hour 5 | Three.js / React Three Fiber basics and a simple 3D device scene. |
| Hour 6 | Debug the end-to-end flow, handle disconnects and revise interview topics. |

## Deliverable
A React dashboard that loads devices and updates telemetry live.

## Completion checklist
- [ ] Explain when WebSocket is preferable to polling or SSE.
- [ ] Receive and parse live messages in React.
- [ ] Update charts/state without a full page refresh.
- [ ] Handle connection close and reconnect safely.
- [ ] Show a basic 3D scene if core integration is complete.
